مهمة جديدة

المزامنة السحابية عبر JSONBin

كيف تُفعّلها (مرة واحدة لكل جهاز):
  1. أنشئ حساباً مجانياً على jsonbin.io.
  2. من صفحة API Keys انسخ مفتاح X-Master-Key الخاص بك.
  3. أنشئ Bin جديداً (يكفي محتوى مبدئي مثل {}) وانسخ Bin ID الخاص به.
  4. الصق البيانات بالأسفل واضغط «اختبار الاتصال» ثم «تفعيل المزامنة».
يُحفظ في متصفح هذا الجهاز فقط، ولا يُكتب داخل الملف أو نسخة JSON.

تغيير الرقم السري
